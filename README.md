## 🎨 Appearance & Theming

### Blur My Shell
Adds a customizable blur effect to the GNOME Shell overview, top panel, dash, and applications. Highly configurable with per-component settings.

🔗 [GitHub](https://github.com/aunetx/blur-my-shell)
🔗 [EGO](https://extensions.gnome.org/extension/3193/blur-my-shell/)
`blur-my-shell@aunetx`

### User Themes
Allows loading custom Shell themes from the user's home directory. Part of the official GNOME Shell extensions package.

🔗 [GitHub](https://gitlab.gnome.org/GNOME/gnome-shell-extensions/-/tree/main/extensions/user-theme?ref_type=heads)
🔗 [EGO](https://extensions.gnome.org/extension/19/user-themes/)
`user-theme@gnome-shell-extensions.gcampax.github.com`

### Auto Theme
Automatically switches between light and dark theme based on time of day.

🔗 [GitHub](https://github.com/dodog/auto-theme)
🔗 [EGO](#)
`auto-theme@dodog.github.io`

### Desktop Cube
Recreates the legendary Compiz desktop cube effect for GNOME Shell. Fully customizable with different cube, cylinder, and sphere modes.

🔗 [GitHub](https://github.com/Schneegans/Desktop-Cube)
🔗 [EGO](https://extensions.gnome.org/extension/4648/desktop-cube/)
`desktop-cube@schneegans.github.com`

## 🖥️ Desktop & Layout

### Dash to Panel
An icon taskbar for GNOME Shell. Combines the application dash and top panel into a single, customizable panel with window list and system tray.

🔗 [GitHub](https://github.com/home-sweet-gnome/dash-to-panel)
🔗 [EGO](https://extensions.gnome.org/extension/1160/dash-to-panel/)
`dash-to-panel@jderose9.github.com`

### Vertigrid
Adds a configurable application grid to the GNOME Shell overview.

🔗 [GitHub](https://github.com/dodog/vertigrid)
🔗 [EGO](#) 
`vertigrid@dodog.github.com`

### GTK4 Desktop Icons NG (DING)
Desktop icons for GNOME Shell, a fork of the original Desktop Icons extension with GTK4 compatibility.

🔗 [GitHub](https://gitlab.com/smedius/desktop-icons-ng)
🔗 [EGO](https://extensions.gnome.org/extension/5263/gtk4-desktop-icons-ng-ding/)
`gtk4-ding@smedius.gitlab.com`

### Add to Desktop
Easily create desktop shortcuts for applications from the app launcher. Requires the "Desktop Icons" extension for the shortcuts to display properly.

🔗 [GitHub](https://github.com/Tommimon/add-to-desktop)
🔗 [EGO](https://extensions.gnome.org/extension/3240/add-to-desktop/)
`add-to-desktop@tommimon.github.com`

### No Overview
Removes the overview that appears when the Super key is pressed, showing the desktop directly.

🔗 [GitHub](https://github.com/fthx/no-overview)
🔗 [EGO](https://extensions.gnome.org/extension/4099/no-overview/)
`no-overview@fthx`

### Start Overlay in Application View
When activating the overview (Super key), shows the application view instead of the window view.

🔗 [GitHub](https://github.com/Hexcz/Start-Overlay-in-Application-View-for-Gnome-40-)
🔗 [EGO](https://extensions.gnome.org/extension/5040/start-overlay-in-application-view/)
`start-overlay-in-application-view@Hex_cz`

## 🔊 Media & Audio

### Media Controls
Display and control currently playing media directly in the top panel. Supports basic playback controls (play/pause, next/prev) and customization options.

🔗 [GitHub](https://github.com/cliffniff/media-controls)
🔗 [EGO](https://extensions.gnome.org/extension/4470/media-controls/)
`mediacontrols@cliffniff.github.com`

### Quick Settings Audio Panel
Adds an audio panel to Quick Settings. Features include moving master volume sliders, application mixer, and relocating media controls. Compatible with GNOME 45–48.

🔗 [GitHub](https://github.com/Rayzeq/quick-settings-audio-panel)
🔗 [EGO](https://extensions.gnome.org/extension/5940/quick-settings-audio-panel/)
`quick-settings-audio-panel@rayzeq.github.io`

### OSD Volume Number
Replaces the OSD volume level icon with an actual number for more precise control.

🔗 [GitHub](https://github.com/Deminder/osd-volume-number)
🔗 [EGO](https://extensions.gnome.org/extension/5461/osd-volume-number/)
`osd-volume-number@deminder`

### Pip on Top
Forces Picture-in-Picture windows to stay on top of other windows.

🔗 [GitHub](https://github.com/Rafostar/gnome-shell-extension-pip-on-top)
🔗 [EGO](https://extensions.gnome.org/extension/4691/pip-on-top/)
`pip-on-top@rafostar.github.com`

## ⚡ System & Utilities

### Systemd Manager Neo
Powerful systemd service and timer manager with monitoring, grouping, and native GNOME integration. Supports timers, typed groups (services/timers), and advanced filtering.

🔗 [GitHub](https://github.com/ladoleo/systemd-manager-neo)
🔗 [EGO](https://extensions.gnome.org/extension/9825/systemd-manager-neo/)
`systemd-manager-neo@ladoleo.local`

### Shutdown Timer
Convenient shutdown timer and alarm for GNOME Shell Quick Settings. Supports poweroff, reboot, suspend, and rtcwake alarm.

🔗 [GitHub](https://github.com/Deminder/ShutdownTimer)
🔗 [EGO](https://extensions.gnome.org/extension/4372/shutdowntimer/)
`ShutdownTimer@deminder`

### Power Menu
Adds a customizable power menu to the GNOME Shell panel with options for shutdown, restart, suspend, and more.

🔗 [GitHub](https://github.com/dodog/power-menu)
🔗 [EGO](https://extensions.gnome.org/extension/10732/power-menu/)
`power-menu@dodog.github.io`

### Bring Out Submenu Of Power Off/Logout Button
Brings out the hidden power off/logout submenu for easier access.

🔗 [GitHub](https://github.com/PRATAP-KUMAR/bring-out-submenu-of-power-off-logout)
🔗 [EGO](https://extensions.gnome.org/extension/2917/bring-out-submenu-of-power-offlogout-button/)
`BringOutSubmenuOfPowerOffLogoutButton@pratap.fastmail.fm`

### Tailscale Status
An unofficial extension to manage and check Tailscale CLI status. Requires Tailscale to be pre-configured. Features include copying node addresses, connecting to exit nodes, and switching accounts.

🔗 [GitHub](https://github.com/maxgallup/tailscale-status)
🔗 [EGO](https://extensions.gnome.org/extension/5112/tailscale-status/) 
`tailscale-status@maxgallup.github.com`

### AppIndicator Support
Support for AppIndicators (KStatusNotifierItems) in the top panel. Useful for background applications like Dropbox, Discord, etc.

🔗 [GitHub](https://github.com/ubuntu/gnome-shell-extension-appindicator)
🔗 [EGO](https://extensions.gnome.org/extension/615/appindicator-support/)
`appindicatorsupport@rgcjonas.gmail.com`

### Bluetooth Battery Meter
Shows battery levels of connected Bluetooth devices directly in the GNOME Shell panel.

🔗 [GitHub](https://github.com/maniacx/Bluetooth-Battery-Meter)
🔗 [EGO](https://extensions.gnome.org/extension/6670/bluetooth-battery-meter/)
`Bluetooth-Battery-Meter@maniacx.github.com`

### Gotify Notifications
Display persistent notifications from a Gotify server in GNOME Shell.

🔗 [GitHub](https://github.com/dodog/gotify-notifications)
🔗 [EGO](https://extensions.gnome.org/extension/8794/gotify-notifications/)
`gotify-notifications@dodog.github.com`

### Home Assistant Extension
Simple GNOME Shell extension for Home Assistant. Control entities, view sensor statuses, and monitor temperature. Requires a long-lived access token.

🔗 [GitHub](https://github.com/geoph9/hass-gshell-extension)
🔗 [EGO](https://extensions.gnome.org/extension/4170/home-assistant-extension/)
`hass-gshell@geoph9-on-github`

### Hide Universal Access
Hides the Universal Access icon from the status bar.

🔗 [GitHub](https://github.com/akiirui/hide-universal-access)
🔗 [EGO](https://extensions.gnome.org/extension/2398/hide-universal-access/) 
`hide-universal-access@akiirui.github.io`
